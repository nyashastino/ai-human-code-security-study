# Licence status

`Repository_Licences.csv` records checks against the exact 30 human repository commits used in the study, with evidence URLs.

- Nine have full, consistent first-party licence files.
- Ten declare MIT or ISC without a full licence file.
- Two have inconsistent MIT/ISC labels (samples 14 and 15).
- Nine have no first-party licence statement found (samples 1, 4, 9, 10, 11, 18, 19, 24 and 26).

Human source code is therefore represented by pinned references in this package. Locally retrieved source is excluded from Git. This audit does not grant redistribution rights, and a dependency's licence does not license the containing application.

Select a licence for the researcher's own scripts and documentation before publication. Do not apply it to third-party code or SonarSource rule descriptions. The archived scanner rules and outputs retain their upstream provenance; licence choices for this public package remain to be completed.
